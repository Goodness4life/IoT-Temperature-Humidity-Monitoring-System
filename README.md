# IoT Temperature & Humidity Monitoring System

## Overview
This project uses ESP8266 and DHT11 sensor to monitor temperature and humidity in real-time. Data is sent to the Blynk IoT platform for remote monitoring.

## Features
•Real-time monitoring  
•Remote control via Blynk  
•IoT-based automation  

## Technologies
•ESP8266  
•DHT11 Sensor  
•Blynk IoT
